# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Assume good intent while discussing ideas, and focus criticism on code and behavior rather than people. Welcome contributors regardless of experience or background.

Harassment, threats, discriminatory language, sexualized attention, deliberate intimidation, doxxing, and publishing another person's private information are not acceptable.

## Scope

This standard applies in repository issues, pull requests, discussions, release conversations, and other project spaces.

## Reporting and enforcement

Do not publish sensitive conduct reports in a public issue. Use a private contact method listed on a maintainer's GitHub profile. If none is available, open a minimal issue asking how to contact the maintainers privately, without naming people or including personal details. GitHub's vulnerability-reporting channel in `SECURITY.md` is for security vulnerabilities, not ordinary conduct reports.

Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when needed to protect the project community. Reports should be handled as privately and impartially as practical.
